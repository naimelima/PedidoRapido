# 📦 Pedido Rápido

Sistema de gerenciamento de pedidos desenvolvido em **C# (.NET)** com integração ao **SQL Server**.

A aplicação permite cadastrar, listar, atualizar e remover pedidos, incluindo cálculo automático da taxa de entrega com base na distância.

---

## 🚀 Funcionalidades

✅ Cadastro de pedidos  
✅ Listagem de pedidos  
✅ Atualização de pedidos por ID  
✅ Remoção de pedidos  
✅ Cálculo automático de taxa de entrega  
✅ Persistência em banco de dados  

---

## 🛠 Tecnologias Utilizadas

- C#
- .NET
- SQL Server
- ADO.NET
- Console Application

---

## 🎯 Objetivo do Projeto

Projeto desenvolvido para prática de:

- Orientação a Objetos (POO)
- Operações CRUD
- Integração com banco de dados
- Estrutura em camadas (Menu / Banco / Model)
- Validação de entrada de dados

---

## 🧮 Regras de Negócio

- Taxa de entrega calculada com base na distância
- Valor total = Valor do pedido + Taxa de entrega
